GROUP MODERATOR (Telethon userbot + website)

Chalu korar niyom:
1. Ei zip er shob file CodeNest e upload koro (main.py ta main file).
2. Job chalu koro, tarpor job er public link kholo.
3. Status tab e main session string paste kore Connect chapo.
4. Groups tab e dekhbe tumi je group gulor admin.
5. Rules tab e rule banao ba default gulo bodlao. Default react:
   🤬 = ban, 🤡 = mute 1 ghonta, 💩 = message delete, 👀 = warn, 🏆 = admin (default bondho)
6. Kono group e message e reply diye .ban .mute 30m .promote likhleo kaj hobe.

Prothome Settings e "Dry-run" tick dile kono kaj hobe na, shudhu Log e dekhabe ki hoto.
Bot token (optional) dile confirm button ar captcha pabe.

Files: main.py core.py actions.py engine.py webapp.py ui.py plugins/ (prottek feature alada file e)
Data: data/ folder e config, log, session thake.
